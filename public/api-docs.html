Bu sayfanın interaktif arayüzü cdnjs.cloudflare.com'dan yüklenir — internet erişimi olmayan (fabrika içi kapalı ağ) bir kurulumda bu sayfa açılmaz. Ham API şeması her zaman, internet gerektirmeden, doğrudan sunucudan okunabilir: GET /api/docs/openapi.json — bunu Postman, Insomnia veya başka bir API aracına içe aktarabilirsiniz.
